# Personal Profile Card

A simple and responsive personal profile card designed to showcase a profile, social links, and essential contact information in a clean, minimal layout.

## Features

* Clean and minimal profile interface
* Responsive design for different screen sizes
* Social and professional profile links
* Personal introduction and contact information
* Built without external UI frameworks

## Tech Stack

* HTML5
* CSS3

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Swetha-Baskaran/personal-profile-card.git
cd personal-profile-card
```

Open `index.html` in your browser to view the profile card.

## Project Purpose

This project was created to practice building a responsive personal interface from scratch using semantic HTML and CSS, with a focus on layout, styling, responsiveness, and clean UI design.
